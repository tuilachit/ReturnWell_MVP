# Security checkpoint — local, not hosted acceptance

- Verified Auth identity/current membership govern every workflow. Independent credential/practice writes require current verified MFA AAL2; caller metadata and actor IDs cannot grant it. The existing database/HTTP permission matrices cover pending/other-practice/assigned/revoked/operator-only actors and direct browser RPC/UPDATE attempts.
- A practice colleague may read referral onboarding progress, but full invitation email is limited to its inviter/current practice owner or admin/operator within the already-authorised workflow. Additive masking runs after original checks, including replay responses.
- App middleware sends no-store, no-referrer, nosniff, DENY, restrictive Permissions-Policy and CSP. Production generates a fresh cryptographic nonce and forwards the trusted CSP to Vinext's nonce-aware SSR/RSC renderer; caller-provided CSP is replaced. Development alone permits Vite inline/eval/HMR. Styles permit inline CSS for existing React layouts. Production build/browser acceptance is separately recorded, not inferred from development success.
- Public invitation endpoints retain random token/per-invitation/recipient limits and consent checks. Browser sign-in cooldown is UX only. Supabase Auth origin rate limits are the direct-origin control; client IP forwarding is not trusted or implemented here. Public signup is disabled in source config.
- Hosted rate-limit/CAPTCHA configuration, redirect inventory, password endpoint/password-protection policy and historical-key rotation require authorised provider review. No finding is marked fixed from a dashboard assumption. Direct Auth abuse review is a blocking pilot-evidence field.
- Signing out clears browser state; it is not proof every issued access token is immediately invalid. Current DB membership/ownership/suspension checks remain necessary. Lost MFA recovery requires independent support verification; no email-only privileged bypass.

Verified provider guidance: [Supabase Auth rate limits](https://supabase.com/docs/guides/auth/rate-limits), [CAPTCHA](https://supabase.com/docs/guides/auth/auth-captcha), accessed 2 October 2026. No hosted setting changed.
